Before You Start

0

Make sure you know whether you are using the hosted page, a local server, or the project folder.

Requirements

What you need

  • A computer running Windows 10/11 or macOS.
  • The font browser page, or the local project folder.
  • Font files ending in .ttf.
  • A Geez input keyboard if you want to type new Geez text.
Starting point

Use the right path

  • Hosted site: open the font browser and click Download font.
  • Local project: run a small server from the project root, then open index.html.
  • Direct install: open a folder such as fonts/Asmara and install the .ttf files.

Good news: you usually do not need administrator rights if you install fonts only for your own user account.

Browse and Download From This Project

1

Use the main page to choose the exact font before installing anything.

  1. Open the font browser.
  2. Choose a collection from the Collection menu, or leave it on All collections.
  3. Type your own Geez sample in Your sample text to compare fonts using real text.
  4. Use Find a font, Arrange by, Cards, and List to narrow the choices.
  5. Turn on Geez alphabets to inspect letter forms with the selected font.
  6. Use Save choice for browser-only favorites. This is saved in your browser storage, not in the font file.
  7. Click Copy for website if you need a CSS @font-face snippet for a web page.
  8. Click Download font on the font card to get the installable .ttf file.

Install the Fonts

2

Install the downloaded .ttf file, or install a whole folder from the local project.

Windows

Install for your user account

  1. If you downloaded one font, open your Downloads folder and find the .ttf file.
  2. If you are installing from the local project, open fonts, then open a collection folder such as Asmara.
  3. For one file, right-click the .ttf file. For a whole folder, press Ctrl + A first.
  4. Choose Install.
  5. Choose Install for all users only if every computer user needs the fonts. This requires administrator access.
  6. Close and reopen Word, your browser, and other apps so they can detect the new fonts.

Windows 11 tip: if you do not see Install, click Show more options first.

macOS

Install with Font Book

  1. If you downloaded one font, open Downloads and find the .ttf file.
  2. If you are installing from the local project, open fonts, then open a collection folder such as Asmara.
  3. Select one or more .ttf files.
  4. Double-click a .ttf file to open Font Book, then click Install Font.
  5. You can also open Font Book and drag multiple .ttf files into it.
  6. Close and reopen the apps where you want to use the fonts.

Enable a Geez Keyboard

3

Fonts control how text looks. A keyboard input lets you type ግእዝ characters.

Windows

Add a Tigrinya or Amharic keyboard

  1. Open Settings.
  2. Go to Time & language > Language & region.
  3. Click Add a language.
  4. Search for Tigrinya or Amharic and add it.
  5. Switch keyboards with Win + Space or the language icon in the taskbar.
macOS

Add an input source

  1. Open System Settings.
  2. Go to Keyboard > Text Input > Input Sources.
  3. Click Add (+).
  4. Search for Amharic or Tigrinya and add it.
  5. Switch keyboards using the input menu in the menu bar, or Ctrl + Space if configured.

Use the Fonts in Microsoft Word

4

Use the desktop version of Word for the most reliable local font support.

  1. Open the Microsoft Word desktop app and create a new document.
  2. Make sure your Geez keyboard is active.
  3. On the Home tab, open the Font dropdown.
  4. Start typing a family name, such as Asmara Sans Geez, Asmara Serif Geez, Keren, Nakfa, Massawa, Senafe, or Tsorona.
  5. Select the font family you want.
  6. If available, choose a specific style such as Regular, Bold, Thin, or SemiBold.
  7. Start typing in Geez.

Common font family names

Asmara Sans Geez Asmara Serif Geez Keren Nakfa Massawa Senafe Tsorona

Note: if the fonts do not appear, fully close Word and open it again.

Sharing tip: Word Online may not use your locally installed fonts. For exact appearance, use Word desktop > Export to PDF and share the PDF.

Use Geez Text with Google Docs

5

Google Docs usually does not use fonts installed on your computer.

Important: you cannot directly import these project .ttf files into Google Docs.

Option 1

Use an available Google font

  1. Open a document in Google Docs.
  2. Open the Font menu.
  3. Click More fonts.
  4. Search for and add a font that supports Geez. Availability can vary.
  5. Select the font in the menu.
  6. Make sure your Geez keyboard is active.
  7. Type your text.

The look may not match this project's fonts exactly, but Geez characters should display.

Option 2

Keep the exact appearance

  1. Create your document in Microsoft Word desktop using the fonts from this project.
  2. Export as PDF using File > Save As or File > Export > PDF.
  3. Upload the PDF to Google Drive and share it.

Warning: if you upload a Word document to Drive and open it with Google Docs, Google may substitute fonts and the layout can change.

Uninstall the Fonts

6

Remove installed fonts when you no longer need them.

Windows

Remove from Settings

  1. Open Settings.
  2. Go to Personalization > Fonts.
  3. Search for a family name, such as Asmara or Keren.
  4. Open the font family page.
  5. Click Uninstall.
macOS

Remove from Font Book

  1. Open Font Book.
  2. Find the font family, such as Asmara or Keren.
  3. Right-click or Ctrl-click the family.
  4. Select Remove.

Troubleshooting Checklist

7

Use this checklist when something does not look or type correctly.

Missing fonts

Fonts do not appear in Word or other apps

  • Close the app completely and reopen it.
  • If still missing, restart your computer.
  • On Windows, confirm installation in Settings > Personalization > Fonts.
  • Confirm you installed the downloaded .ttf file, not only previewed it in the browser.
Typing

You see Latin letters instead of ግእዝ

  • Make sure your Geez keyboard is selected, not English.
  • On Windows, use Win + Space.
  • On macOS, use the input menu in the menu bar or your configured shortcut.
Styles

Bold or italic does not change anything

  • Not all fonts include every style.
  • In Word, select the actual weight from the font family, such as SemiBold, Bold, or Thin.
  • Avoid relying only on simulated bold or italic.
Sharing

Other people do not see the correct font

  • If they do not have the fonts installed, their system may replace them.
  • Share a PDF when identical rendering is required.
